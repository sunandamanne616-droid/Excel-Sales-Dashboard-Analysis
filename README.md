# Excel-Sales-Dashboard-Analysis
# 📊 Bike Sales Dashboard (Excel)

## Overview

This project analyzes customer demographics and purchasing behavior using Microsoft Excel. The dashboard provides interactive visualizations to help understand the factors influencing bike purchases.

---

## Objectives

- Analyze customer purchasing behavior
- Identify income trends across genders
- Study customer age distribution
- Analyze commuting distance
- Build an interactive Excel dashboard using slicers

---

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Conditional Formatting

---

## Dashboard Features

✔ Interactive Slicers

- Marital Status
- Purchased Bike
- Education Level

✔ Visualizations

- Average Income per Purchase
- Customer Age Category
- Customer Commute Distance

---

## Key Insights

- Male customers purchasing bikes have a higher average income.
- Middle-aged customers represent the largest customer segment.
- Customers with shorter commute distances are more likely to purchase bikes.
- Dashboard filters allow dynamic exploration of customer behavior.
